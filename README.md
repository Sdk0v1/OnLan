# Mini Logistics Delivery Analytics — OnLan
A small end-to-end analytics project conducted at **OnLan** — a logistics company specializing in international freight transportation from Ukraine to European countries.


## Project Overview



The project demonstrates a complete analytical workflow: from working with a relational database, SQL analysis, and data quality validation to exploratory analysis in Google Sheets and the development of an interactive Power BI dashboard.

The goal of the project was to transform operational data into actionable business insights related to order volume, revenue, profitability, delivery performance, delays, and driver performance.

---

## Business Problem

Management did not have a clear, data-driven understanding of the company's operational performance.

The main challenges were:

* No centralized visibility into total orders, revenue, and profit
* No clear understanding of the busiest and most profitable international routes
* No systematic monitoring of delivery delays
* Limited information for comparing driver and delivery type performance
* No analysis of monthly profit trends or potential seasonality
* Business decisions were made without sufficient analytical support

The project creates an analytical layer using **SQL and Power BI** to address these business needs.

---

## Business Questions

The analysis was built around the following questions:

1. How many orders does the company process, and how does order volume change over time?
2. What are the company's total revenue and profit?
3. Which international routes are the most popular and profitable?
4. What percentage of orders are delayed?
5. Which drivers and delivery types perform most efficiently?
6. How does profit change month by month, and are there signs of seasonality?

---

# Data

The project uses a synthetic dataset representing international freight transportation operations.

### Dataset Size

* **500 orders**
* **20 drivers**
* **8 Ukrainian origin cities**
* **8 European destination cities**
* Multiple delivery types and order statuses

### Main Entities

#### `orders`

| Field             | Description                   |
| ----------------- | ----------------------------- |
| `order_id`        | Unique order identifier       |
| `order_date`      | Order date                    |
| `city_from`       | Origin city                   |
| `city_to`         | Destination city              |
| `delivery_type`   | Delivery type                 |
| `weight_kg`       | Shipment weight               |
| `delivery_cost`   | Delivery cost                 |
| `delivery_status` | Delivery status               |
| `delivery_days`   | Number of delivery days       |
| `profit`          | Profit generated by the order |
| `driver_id`       | Driver identifier             |

#### `drivers`

| Field          | Description              |
| -------------- | ------------------------ |
| `driver_id`    | Unique driver identifier |
| `driver_name`  | Driver's name            |
| `vehicle_type` | Vehicle type             |

### Database Relationship

The tables are connected through a **one-to-many relationship**:

```text
drivers.driver_id
        │
        │ 1 : N
        ▼
orders.driver_id
```

One driver can handle multiple orders, while each order is assigned to one driver.

# Power BI Dashboard

## Logistics Performance Dashboard

A one-page interactive Power BI dashboard was created to provide a quick overview of key logistics performance indicators.

### KPIs

The dashboard contains five main KPIs:

* **Total Orders** — total number of orders
* **Total Revenue** — total revenue
* **Total Profit** — total profit
* **Delay Rate** — percentage of delayed orders
* **Average Delivery Days** — average delivery duration

A total of **6 custom DAX measures** were created to calculate the key metrics.

### Visualizations

The dashboard contains:

1. **Orders by Month**
   Shows the monthly trend in order volume.

2. **Orders by Destination City**
   Shows the most popular destination cities.

3. **Orders by Delivery Type**
   Compares demand across different delivery types.

4. **Completed vs Delayed Orders**
   Shows the relationship between completed and delayed orders.

5. **Top Drivers by Profit**
   Identifies the drivers generating the highest total profit.

### Filters

Users can dynamically filter the dashboard by:

* Date
* Destination City
* Delivery Type
* Driver

This allows users to move from a high-level overview to a detailed analysis of specific periods, routes, delivery types, or drivers.

# Key Business Insights

The analysis produced several important findings.

### 1. Bucharest is the Most Popular Destination

**Bucharest** was the busiest destination city:

* **76 orders**
* **15.2%** of all orders

This indicates particularly high demand for deliveries to Bucharest compared with other destinations.

### 2. Vinnytsia → Berlin is the Most Profitable Route

The most profitable individual route was:

**Vinnytsia → Berlin**

Results:

* **17 orders**
* **$3,737 total profit**

This route generated the highest total profit among the analyzed routes.

### 3. Delivery Delay Rates Vary by Delivery Type

The overall delay rate was:

**14.8%**

Performance differed between delivery types:

| Delivery Type | Delay Rate |
| ------------- | ---------: |
| Standard      |      18.8% |
| Express       |      12.4% |

Standard deliveries had the highest delay rate, while Express deliveries demonstrated better delivery reliability within this dataset.

### 4. Cargo Has the Highest Profit per Order

The average profit per Cargo order was:

**$282.61**

For comparison:

**Standard — $100.12**

Therefore, the average profit per Cargo order was almost **3 times higher** than for Standard orders.

### 5. Top Drivers by Profit

The top three drivers by total profit were:

| Rank | Driver            | Total Profit |
| ---: | ----------------- | -----------: |
|    1 | Maksym Bondarenko |       $8,111 |
|    2 | Artem Kravets     |       $7,470 |
|    3 | Roman Tkachenko   |       $6,488 |

These results provide a basis for further analysis of the factors affecting driver profitability, such as order volume, delivery types, routes, or vehicle types.
